# Creative Agency — Studio & Portfolio

A modern design and development studio portfolio built with React, TypeScript, Vite, and Tailwind CSS. Originally ported from the Colorlib WordPress block theme and migrated into a responsive, high-performance web application for AI Studio.

## Features

- **Multi-Palette Color Scheme Switcher**: 6 authentic palettes (Azure, Violet, Coral, Emerald, Ink, Midnight) with live CSS custom property switching.
- **Visitor Dark Mode**: Seamless toggle between light and dark themes with persistent user preference.
- **Selected Works**: Staggered project showcase featuring interactive case studies for Nookdesk, Whisk, Harrow & Pine, and Arcade Club.
- **Interactive Quick Facts**: Animated statistics counters for shipped products, clients, and design awards.
- **Full Studio Pages**:
  - **Home**: Opening statement, client logos, staggered projects, quick facts, services band, studio photo strip, latest essays, and contact CTA.
  - **About**: Studio background, manifesto/values, senior leadership profiles, and 12-year milestone timeline.
  - **Work**: Category-filtered case studies with in-depth modals.
  - **Services**: 4-phase delivery framework, capabilities breakdown, and interactive scope/budget estimator.
  - **Blog**: Searchable studio journal with reading mode and interactive reader comments.
  - **Contact**: Validated project brief form with budget tier picker, non-disclosure agreement assurance, studio coordinates, and FAQ accordions.

## Development

```bash
# Install dependencies
npm install

# Start development server on port 3000
npm run dev

# Build for production
npm run build

# Run type checks
npm run lint
```
